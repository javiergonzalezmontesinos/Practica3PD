# Practica 3 - Ejercicio Voluntario: Modo AP (Access Point)

## Objetivo
Configurar la ESP32 como punto de acceso WiFi (AP) para crear una red inalámbrica independiente, permitiendo que otros dispositivos se conecten directamente a ella y accedan a un servidor web local, según los requisitos del enunciado opcional.

## Logros alcanzados
✅ **Red WiFi autónoma creada**:  
   - Nombre visible: `ESP32_AP`  
   - Sin dependencia de routers externos  

✅ **Servidor web accesible**:  
   - Página básica disponible en la IP `192.168.4.1`  
   - Compatible con cualquier navegador en dispositivos conectados  

✅ **Funcionalidad completa**:  
   - Comunicación estable con múltiples dispositivos  
   - Integración perfecta con el ejercicio original (modo STA)
