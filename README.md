# Práctica 3 - Parte B: Comunicación Bluetooth

## Objetivo
Establecer comunicación inalámbrica bidireccional entre la ESP32 y un dispositivo móvil usando Bluetooth clásico, según los requisitos del enunciado:

1. Configurar la ESP32 como dispositivo Bluetooth con nombre identificable ("ESP32test").
2. Permitir el intercambio de mensajes en tiempo real entre el Monitor Serie y una app móvil.

## Resultados obtenidos
✅ **Emparejamiento exitoso**:  
La ESP32 es reconocida correctamente por el móvil bajo el nombre configurado.

✅ **Comunicación funcional**:  
- Mensajes escritos en el Monitor Serie se reciben en la app móvil.
- Mensajes enviados desde la app se muestran en el Monitor Serie.

✅ **Estabilidad**:  
La conexión mantiene estabilidad durante periodos prolongados de uso.
